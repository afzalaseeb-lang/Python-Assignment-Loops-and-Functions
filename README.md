# Python-Assignment-Loops-and-Functions
A Python programming assignment covering While Loops, For Loops, Range Function, Control Statements (break, continue, else), and User-Defined Functions through practical programs such as a Number Guessing Game, Multiplication Table Generator, and BMI Calculator.

#Overview

This repository contains Python Assignment, focusing on loops, control statements, and user-defined functions. The assignment demonstrates the practical application of Python programming concepts through simple programs.

#Topics Covered

While Loop

For Loop

Range Function

Control Statements: break, continue, and else

User-Defined Functions

Function Parameters and Return Statements

User Input and Output

#Programs Included

1. Number Guessing Game

Generates a random number between 1 and 10.

Allows the user a maximum of three valid attempts.

Uses a while loop and control statements (break, continue, and else).

2. Multiplication Table Generator

Accepts a number from the user.

Uses a for loop and range function.

Generates a multiplication table from 1 to 10.

3. BMI Calculator

Defines a function calculate_bmi(weight, height).

Calculates Body Mass Index using the BMI formula.

Uses function parameters and return statements.

#Technologies Used

Python 3
